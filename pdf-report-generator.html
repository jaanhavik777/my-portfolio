Problem

Exploring a new dataset often means rebuilding the same summary tables and charts. The generator automates that first pass.

Architecture

  1. CSV upload
  2. Column detection

  4. PDF download

Technical walkthrough

Choose analyses by column type

Numeric columns support distributions and correlations. Categorical columns produce frequency summaries. Date columns can support time-series views.

Separate the report engine from the web layer

The Flask app receives uploads and serves the generated PDF. The report engine can also run from the command line, so the same report workflow is available without the web UI.

Bound the work per request

The documented upload cap is 50 MB. Chart generation and rendering depend on dataset size, so larger CSVs can take longer to process.
