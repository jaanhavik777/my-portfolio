PDF Report Generator

Turn a CSV into a shareable analysis.

RepositoryLive demo

Why I built it

CSVs are a pain to read 😭 I just want to see the results! When I open a file full of rows and columns, I want to know what stands out, what shows up most often, and whether there’s a pattern worth looking into. Making a bunch of charts by hand feels like a lot of work just to get that first look. So I built a tool that takes the CSV and gives me a PDF I can skim and send to someone else.

Architecture

  1. CSV upload

How I built it

Starting with the file I actually get

The Flask route checks the upload and reads the CSV stream with pandas. The generator looks at which columns are numeric or categorical and uses that to decide what can go in the report. Numeric data can support a distribution or correlation plot, and categorical data can show the most common values.

Turning the first pass into a document

I use Matplotlib to generate the charts and ReportLab to lay them out with descriptive statistics, category summaries, and a preview of the first ten rows. The uploaded file does not need to use a preset column naming scheme.

Making it usable from the web and the terminal

I kept the report engine separate from Flask. The web version gives people an upload and download flow. The command-line entry point uses the same engine when I’m working with a file locally.

Where it stands

The Render demo takes a CSV and returns a downloadable PDF. The app caps uploads at 50 MB, and generating charts in the upload request means larger reports can make people wait. If larger files became common, I’d try moving generation into a background job and showing progress.
