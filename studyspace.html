StudySpace

A shared workspace for study groups.

RepositoryLive demo

Why I built it

My friends and I study together every exam season. Half the work sometimes feels like figuring out when we’re meeting, finding the notes someone shared, and keeping track of the conversation. I wanted us to have one place to do all of that, then start a timer and actually get some studying done. That’s where StudySpace came from.

Architecture

  1. React workspace
  2. Express API
  3. MongoDB records
  4. Socket.IO updates

How I built it

Building around a study session

I broke the React interface into views for sessions, chat, a resource hub, and a Pomodoro timer. A group can have a session with notes and a conversation, while direct chat gives people somewhere to check in individually.

Deciding what should be saved and what should happen live

I used Express and MongoDB for records such as sessions and messages, so there is history to load when someone opens a view. I used Socket.IO for room updates and typing indicators, so people can see what’s happening while they’re there.

Making the chat work across views

The client joins the relevant room and cleans up its subscriptions when it leaves. For direct chats, the server checks room membership before allowing a subscription. The client listens for new messages, edits, reactions, and typing events, each of which updates a different part of the chat view.

Where it stands

The frontend is deployed on Vercel. The code ties together sessions, chat, resources, and a timer in one workspace. I’d like to test what happens when two people use the same session and one loses their connection, especially whether the view catches up cleanly when they return.
