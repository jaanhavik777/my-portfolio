Hybrid music recommendations with Spotify playlist creation.

RepositoryLive demoDemo pending

Problem

Turn a natural-language music request into a personalized Spotify playlist.

Architecture

  1. Natural-language prompt
  2. Collaborative + content filtering
  3. Hybrid ranker
  4. Spotify playlist

Technical walkthrough

Candidate generation

Collaborative filtering uses patterns in user interactions. Content-based filtering uses attributes of tracks. The two approaches capture different signals, so the hybrid ranking stage can combine their outputs.

From prompt to playlist

The Streamlit interface accepts a natural-language music request. Retrieval and ranking select tracks, then a separate playlist component calls the Spotify Web API. This boundary lets ranking tests run independently of Spotify.

Testing the ranking

The project uses Pytest for unit tests and top-10 metrics for offline recommendation evaluation. Hit Rate@10 measures whether the top ten contains any relevant item. Precision@10 measures how much of the returned list is relevant. Recall@10 measures how much of the relevant set the list recovers.

Interpreting the dataset

The dataset covers more than 176,000 tracks and 1,200 users. Those counts describe the evaluation inputs. The top-10 metrics are the way to assess retrieval quality and compare ranking approaches.
