Technical walkthrough

Indexing source structure

AST parsing extracts structural metadata such as function boundaries and names. File and function references keep retrieved code tied to a navigable location, which matters when multiple modules contain similar implementations.

Semantic retrieval

Sentence Transformers encode code and natural-language queries as vectors. FAISS finds contextually related snippets, while structural metadata supplies the file and function references needed to inspect a match.

Grounding the generated answer

FastAPI handles the query. Retrieved snippets are passed to the local Ollama model as context for generation. The resulting answer can refer back to source locations, giving readers a way to verify how the code behaves.

The local deployment tradeoff

Local indexing and inference keep source context on the host. Hardware affects response time, and answer quality depends on whether retrieval finds the right context. A useful evaluation would measure retrieval relevance and reference accuracy independently of prose quality.
